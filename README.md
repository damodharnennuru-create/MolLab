# Cheminformatics Virtual Lab

Apple-style multipage Streamlit app: Molecule Viewer, Property Calculator, Similarity Search, Dataset Explorer.

**Live app:** _add URL after deploying_

## Run locally
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
